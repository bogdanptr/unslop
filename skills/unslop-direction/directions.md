# Starting directions

Seven archetypes with the five dials set. Each is a place to start. Change at least one dial for the product in front of you.

Which ones suit which kind of screen:

| Kind of screen | Start from |
| --- | --- |
| Work: dashboards, tables, admin, editors | Instrument, Mono utility, Editorial for document-like records |
| Form: settings, checkout, sign-up | Mono utility, Editorial, Tactile for consumer products |
| Collection: feeds, catalogs, galleries | Content-led, Mono utility |
| Focus: a summary, a home, a detail view | Any, chosen by the subject |
| Marketing: landing and pricing pages | Editorial, Graphic, Content-led with real product imagery, Atmospheric when the subject calls for it |
| Flow: onboarding, wizards | The product's main direction at medium strength |

A product has one direction across all its screens. The kind of screen changes its strength, not its identity.

## Atmospheric

The background is the sky or the light of a time of day, and the interface floats on it.

| Dial | Setting |
| --- | --- |
| Atmosphere | A vertical gradient of a real sky: dawn, dusk, night, overcast. 3 or 4 stops, a little grain |
| Signature | A figure drawn as an arc, a horizon or a path across that sky |
| Type voice | Soft geometric or humanist sans, large figures at 300 |
| Material | Glass, one level |
| Accent source | The warmest or brightest stop of the gradient |

Fits sleep, weather, meditation, habits, travel. Does not fit dense tables or long reading. Text contrast is the main risk, since a sky has light regions and dark ones.

## Instrument

The screen is a precise tool. Numbers are the decoration.

| Dial | Setting |
| --- | --- |
| Atmosphere | Near-black or near-white, neutral, tinted 1 to 2 percent toward the accent hue. A faint grid or ruler is allowed |
| Signature | Figures in a mono with tabular numerals, fine rules, a scale with tick marks where one value leads |
| Type voice | A grotesque with a matching mono for figures, tabular numerals, tight tracking |
| Material | Flat. Hairlines, no shadows |
| Accent source | One signal color used only on live or selected data |

Fits finance, analytics, developer tools, trading, monitoring. Does not fit consumer wellness.

## Editorial

The screen reads like a well-set page.

| Dial | Setting |
| --- | --- |
| Atmosphere | Paper: a warm off-white, or a deep ink for dark |
| Signature | A serif for headings and large figures, generous margins, hairline rules in place of cards |
| Type voice | A serif for display with a quiet sans for interface text |
| Material | Paper. No cards where rules and space will do |
| Accent source | One ink color: a red, a blue, a green, used sparingly on links and one action |

Fits reading, news, notes, journaling, long-form, portfolios. Does not fit dashboards with many live figures.

## Tactile

Surfaces feel like soft physical objects.

| Dial | Setting |
| --- | --- |
| Atmosphere | A warm neutral: sand, clay, stone. Flat or a very slight vertical shift |
| Signature | Soft rounded shapes: chunky controls, a vessel that fills, a stack |
| Type voice | A rounded or humanist sans at medium weights |
| Material | Matte. Large radii, soft layered shadows tinted with the background hue |
| Accent source | One earthy or pastel color from the same temperature as the neutral |

Fits wellness, food, family, education, personal finance for consumers. Does not fit tools that must feel exact.

## Mono utility

Almost no color. Hierarchy from type and space alone.

| Dial | Setting |
| --- | --- |
| Atmosphere | A single neutral, light or dark |
| Signature | Type itself: wide jumps between few sizes, one large figure or word where the view has one |
| Type voice | One grotesque with real character, used at few sizes with wide jumps between them |
| Material | Flat. Fill steps of 3 to 5 percent, no strokes |
| Accent source | A single saturated color, on one element per view |

Fits productivity, tasks, calendars, messaging, settings-heavy apps. The risk is looking unfinished, so spacing has to be exact.

## Content-led

The interface steps back and the user's content supplies the color.

| Dial | Setting |
| --- | --- |
| Atmosphere | Taken from the content: the dominant color of a cover, a photo, a product shot, blurred large behind the screen |
| Signature | The content at full size: a cover, a photo, a product, and one consistent crop for every item |
| Type voice | A neutral sans that does not compete |
| Material | Glass over the content color, or flat on black |
| Accent source | Sampled from the current content, so it changes per item |

Fits music, video, podcasts, commerce, galleries, social. Needs real imagery. With placeholder gray boxes it collapses, so keep the source's images.

## Graphic

Flat shapes and confident color.

| Dial | Setting |
| --- | --- |
| Atmosphere | A solid saturated field, or two fields split by a hard edge |
| Signature | Bold geometric shapes: a heavy headline, a block that grows, a segmented bar, a count of objects |
| Type voice | A heavy display face for one line, a plain sans for the rest. The one direction where large text stays bold |
| Material | Flat, hard edges, no blur, no shadow |
| Accent source | A second saturated color that contrasts the field |

Fits games, kids, social, events, fitness challenges. Tiring on screens people stare at for hours.

## Choosing between two

When two archetypes fit, choose by how long people look at the screen. A screen opened for ten seconds a day can carry atmosphere. A screen worked in for hours needs the quieter one.
